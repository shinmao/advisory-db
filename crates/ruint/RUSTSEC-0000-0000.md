# Unsoundness of safe `reciprocal_mg10` leading to out-of-bounds access

Affected versions of this crate contain a soundness issue in the safe public API `reciprocal_mg10` function located in `src/algorithms/div/reciprocal.rs`.

The function uses `debug_assert!(d >= (1 << 63))` to check that the parameter `d` is at least 2^63. However, `debug_assert!` is compiled out in release mode, allowing callers to pass invalid values such as `0`.

When `d` is `0`, the code calculates `d9 = d >> 55`, which results in `0`. Subsequently, the expression `(d9.0 - 256)` underflows to a very large number, causing an out-of-bounds access when used as an index in `TABLE.get_unchecked((d9.0 - 256) as usize)` at line 87.

This allows safe code to trigger undefined behavior, violating Rust's soundness guarantees.

The issue should be fixed by replacing `debug_assert!` with `assert!` to ensure the precondition is enforced in all build configurations, or by making the function `unsafe` and documenting the safety requirements.
